# Route map (proposed)

Proposed November 23, 2026. This maps every source URL in [ROUTE-INVENTORY.md](ROUTE-INVENTORY.md) and [archive-urls.json](../discovery/2026-11-23/archive-urls.json) to a new route. Readable source paths are kept. Awkward ones get clean routes: `news-2`, `/new-clients/` under a "New Patients" label, encoded FAQ slugs, and duplicated relative paths. Every changed source URL gets a permanent (301) redirect in `static/_redirects`, generated by T-004. Slash and no-slash variants of each source URL redirect too.

This is a proposal: T-004 turns it into the redirect file, and changes to the map go through that ticket.
