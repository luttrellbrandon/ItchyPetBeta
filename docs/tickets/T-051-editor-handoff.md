# T-051 Editor handoff

**Stage:** 4 Launch · **Depends on:** stage 1–2 content tickets · **Type:** Documentation · **Clinic input:** the content editor's name and email

## Goal

The clinic's single content editor can do common tasks alone.

## Scope

- Invite the editor to Sanity with an Editor role. The developer keeps an Administrator account for emergencies (PLAN.md).
- Tidy the Studio for a non-technical user:
  - group documents by section, with plain-language field descriptions
  - required alt text on every image, with a help hint
  - hide technical fields such as legacy paths
- Write a short illustrated guide (`docs/EDITOR-GUIDE.md`, plus a printable PDF if wanted) covering:
  - change hours
  - edit a bio and photo
  - add or remove a banner
  - write a news article
  - replace a handout
  - crop a photo
  - how long publishing takes
  - how to undo a change
- Hold a walkthrough session. The PLAN.md stage 5 test: the editor changes hours, a bio and a promotion with no help, and the public site shows each change correctly.

## Acceptance criteria

- The editor completes the three PLAN.md tasks without developer help.
- The guide is in the repo and the editor has a copy.
